# Wordle：超越“数学最优解”

[English](README.md)

2026-09-27 后续归档：[后续实验报告](FOLLOWUP_REPORT.zh-CN.md)。包含本轮无效改进、Jev 收益归因、数据泄漏风险与六轮保证的边界；原始数据和代码均已保存，`bash reproduce_followup.sh` 可核对归档。报告同时澄清下文旧表述：T0 是原名单上的启发式基线，并非精确最优策略；P2 使用名单身份划分类别，但不把候选硬裁剪到名单内；受限动作树搜索不是全动作穷举。

Wordle 的教科书最优解是经过证明的：用 SALET 开局，平均 3.42 次猜中。但这个证明有一个前提：答案一定出自最早那份 2,315 个词的原始名单，而且每个词概率相同。这个前提已经不成立了，纽约时报在往答案里加新词，2026 年 2 月起还开始重复出旧题。

这个项目做了一个不看答案名单的求解器，由三部分组成：

- **Jev 词先验**：用 TypeSafe 的 Jev（一种回答预设类型问题并给出概率的“System One”模型），给全部 12,972 个合法词打“像不像答案”的分；
- **真实历史答案**：从纽约时报接口取的 1,925 天；
- **普通的信息量搜索**。

在逐日回测里检验，每一天只能用那天之前公布的答案：

| 求解器（2025-01-01 至 2026-09-25，共 633 天） | 平均次数 | 找不到答案的天数 | 3 次内猜中 |
|---|---|---|---|
| 教科书最优（原始名单 + SALET） | 3.49* | **51** | 50.1% |
| 教科书，再去掉出过的词 | 3.09* | **76** | 71.9% |
| 不看名单，Jev + 词频先验（不用历史） | 3.58 | 0 | 48.0% |
| **不看名单，历史感知先验 + Jev（本项目）** | **3.10** | **0** | **79.3%** |

\* 只统计答案还在候选里的那些天。其余日子里候选会被筛空，求解器无词可猜。所有方案都没有超过 6 次的局。

两边都能找到答案的日子做配对比较，历史感知版比教科书最优平均少猜：

- 2025 年：0.42 次（95% 置信区间 0.35–0.49）；
- 2026 年：0.50 次（0.41–0.59）。

而且它一天都没有找不到答案。

## 结论

- **把现实描述准，比把搜索做精更值钱。** 各部分分别少猜多少次：

  | 做了什么 | 少猜几次 |
  |---|---|
  | 用上真实历史答案 | 约 0.48 |
  | Jev 词先验（消融实验测得） | 约 0.06 |
  | 整棵决策树的穷举搜索，代替一步估算 | 约 0.01～0.02 |

- **别把“从没发生过”写死。** “答案不重复”这条规律维持了四年半。2026-02-02，史上第一个答案 CIGAR 又出现了。把出过的词直接删掉的方案，2026 年有 57 天找不到答案。给每一类词都留一点概率、按近期数据自动调整的方案，一天都没失手。
- **Jev 适合当先验，不适合自己玩。** Jev 自己玩平均 4.19 次，比不用任何先验的纯算法还显著更差；判断一个词和颜色反馈是否矛盾，只有 61% 的准确率。接进求解器当先验，能把“不知道名单”带来的损失追回约四分之三。给 12,972 个词打一遍分，每种提示词花 1.4～7.6 美分。
- **提示词很关键，也要警惕“背答案”。** 讲清规则、按档位打分，区分效果最好（AUC 0.976）。提示词里只要多提一句“Wordle”，AUC 就从 0.911 涨到 0.961，说明 Jev 很可能见过答案名单。
- **两个如实报告的无效改进。** 一个是更精确校准的先验：2026 年每天的对数似然高了 0.22 bit，差异显著。另一个是重新调参的打分公式。两者都没能减少猜测次数，见实验 12、13。

完整的实验记录见 [EXPERIMENTS.md](EXPERIMENTS.md)（英文），包括每一个实验、所有数字、注意事项和失败的尝试。

## 工具

`tool/` 是一个单文件网页，用法：

1. 输入每次猜的词，点格子把颜色改成和游戏里一样。
2. 它会给出下一步推荐，并按概率列出剩下的候选词。
3. 猜中后，它会自动把当天的答案记进历史，所以历史不会过期。

Jev 的打分是事先离线算好、烘焙进页面的，所以全部计算都在浏览器里完成，不调用任何接口，也不需要密钥。想用自己的密钥重新打分或试新的提示词，运行 `experiments/jev_score_words.py`，再运行 `experiments/build_prior.py` 和 `tool/build.py`。

```bash
# 仓库已附带本次回测的固定历史快照；复现时不要先覆盖它。
python3 experiments/backtest.py P2s,P2,P0,T0,T1  # 生成 results/backtest_summary.json，网页会用到
python3 tool/build.py                            # -> dist/wordle-solver.html
python3 tool/parity_check.py                     # 核对浏览器引擎和 Python 代码的结果一致
```

## 目录

```

data/          词表和每个词的先验打分（来源和协议见 data/README.md）
results/       重跑得到的日志和 JSON；original_logs/ 是最初那次运行的原始日志；
               jev_examples_2026-09-30/ 保存 8 个示例词完整的 Jev 原始请求和返回
tool/          engine.js（浏览器求解器）、template.html、build.py、parity_check.py
reproduce.sh   重跑全部确定性实验（4 核约 75 分钟）
```
