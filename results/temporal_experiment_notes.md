# 近期排词规律与首词实验

日期：2026-09-27。未调用 Jev 或其他付费模型 API；未修改正式求解器。

## 结果

本轮没有找到可采用的提升。固定 SALET 的结构特征版本与原版持平；加入类别节奏、或用现有单步启发式自适应选择首词，成绩均未改善。

同一批 64 个日期，从 2026-01-01 至 2026-09-25 的 268 天中，用 `random.Random(20260927).sample` 固定抽取：

| 方案 | 总回合 | 平均回合 | 超过六次 | 相对原版：改善／持平／退步 |
|---|---:|---:|---:|---|
| 原版 P2＋SALET | 196 | 3.062500 | 0 | — |
| 结构时序特征＋SALET | 196 | 3.062500 | 0 | 0／64／0 |
| 结构＋类别节奏＋SALET | 198 | 3.093750 | 0 | 0／62／2 |
| 原版 P2＋启发式自适应首词 | 199 | 3.109375 | 0 | 12／37／15 |
| 新先验＋启发式自适应首词 | 202 | 3.156250 | 0 | 11／36／17 |

自适应首词沿用 `common.choose`，在全部 12,972 个合法猜词中选择；不是完整决策树意义上的最优首词。原先验选择 RAISE 61 天、SANER 3 天；新先验选择 RAISE 60 天、SANER 4 天。逐日对比有 3 天首词改变。原先验自适应版本作为对照，避免把换首词算法本身的影响归给新先验。

整个 2026 年已知的 268 天上，结构版本的平均真实答案 log2 概率比原版低 0.013745 bits；完整版本低 0.005110 bits。没有观察到整体预测增益。两个描述性区间均包含零。

## 方法与边界

固定六个结构特征：最近七天的同首字母、同尾字母、同末两字母比例；与最近三天答案的独立字母集合 Jaccard 重合；重复字母比例与近期变化的交互；基础先验低概率程度与近期变化的交互。最后一项是代理量，不是实测难度。

结构版本只在 P2 的三个类别内部重排，保持类别总概率。完整版本另加两个类别特征：距最近重复答案事件、距最近首次使用原词表外答案事件的天数。间隔截断于 30 天；每类在当时已经观察到至少八次事件后才启用该特征。

2026-01-01、04-01、07-01 各拟合一次，每次仅使用此前 365 天。固定 L2=2，对总负对数似然加 `||beta||²`，没有根据本轮成绩搜索正则或特征窗口。季度内逐日特征仅读取前一天及更早的答案。

保留全部合法词的严格正概率；只有游戏颜色反馈可以排除候选。新增训练与预测代码通过时间边界、零系数还原 P2、类别质量守恒、冷启动门槛和正概率检查。全部季度优化均收敛。

这是已被研究过的历史数据上的探索实验，不能称为独立的新测试集。新增时序拟合的 past-only 性质也不替原先的离线模型评分证明不存在历史记忆。

原始历史快照有 1,925 天，SHA256 为 `e9b4f1592b313cf03e8784c602d117ab49024834d7ad880a318a96d0230a4187`。原版 633 日结果已逐日复现：1,961 回合，平均 3.0979462875，零差异。本轮 64 日原版也与保存结果完全匹配。

## “一定解出”的准确范围

本轮全部 64 天、全部五个方案都在六次内解出。这是有限样本事实，不是全词表的六次保证。

固定 2026-09-25 的 P2 先验与 SALET，以全部合法词分别作为假设答案，原版压力遍历在 60 秒内完成 9,492／12,972 个答案，其中已发现 344 个超过六次。遍历未完成，这两个计数是已覆盖部分，不能当作完整词表的最终分布。

明确反例已独立复现：假设答案为 GINGS，原版路径是：

`SALET → HOIKS → VIRUS → FINDS → WINGS → PINGS → ZINGS → MINGS → BINGS → GINGS`

共十次。这不代表 GINGS 是实际 NYT 某日答案，也不否定历史 633 天全部六次内成功；它说明原版尚无“对全合法词表六次必胜”的性质。

词表身份补充：GINGS 出现在仓库的 `data/allowed.txt`（允许猜测词表），不在原始 2,315 词答案表，也未出现在用户提供的 1,925 天历史答案中。没有在当前 NYT 客户端实测其接受情况。这个反例针对“允许猜测词表中的任何词都可能成为答案”的额外压力条件，不能当作实际 NYT 选词中的失败案例。

均值口径补充：本轮 3.0625 是原版在抽取的 64 天上得到的 196／64；原先 3.097946 是原版在全部 633 天上的 1,961／633。结构时序版本在相同 64 天也为 196 回合，因此没有把全量成绩从 3.098 降到 3.0625。

新增证书检查器仅在完整覆盖所有传入候选、且每条路径不超过剩余回合时返回 TRUE。FALSE 需要穷尽或有效必要界；预算耗尽返回 UNKNOWN。完整 SALET 六次树的首轮 30 秒认证返回 UNKNOWN，并未证明可行或不可行。

第二次快速证书搜索严格运行 120 秒，也返回 UNKNOWN。内部为 193 个非绿色首反馈分支中的 191 个构造了后续树，但反馈码 109（126 个候选）和 19（98 个候选）仍未解决；没有完整树，因此没有完整树的独立验证。这不证明不存在六步策略。记录见 `results/six_turn_salet_fast_certificate.json`。没有完整证书时，不采用新策略来承诺六次必胜。
