# Data

The code in this repository is MIT-licensed (see `../LICENSE`). The files in this folder come from different
sources and carry their own terms.

| File | What it is | Source / license |
|---|---|---|
| `allowed.txt` | The 12,972 words Wordle accepts as guesses (sorted) | The original Wordle lists, taken from the npm package [`wordle-words`](https://www.npmjs.com/package/wordle-words) (MIT). Wordle was created by Josh Wardle and is now owned by The New York Times. |
| `answers.txt` | The original 2,315-word answer list (sorted, no dates) | Same as above |
| `priors/jev_*.json` | For every accepted word, the probability or score that Jev returned for five different prompts (see `experiments/jev_score_words.py`) | Outputs of TypeSafe's Jev model (`jev-latest`, September 2026), generated by the author. Released under CC BY-SA 4.0, like the rest of the derived data. |
| `priors/wordfreq_zipf.json` | Zipf word frequency of every accepted word | Computed with [wordfreq](https://github.com/rspeer/wordfreq) 3.1.1 by Robyn Speer. Its data is CC BY-SA 4.0, so this file is too. |
| `tool_prior.json` | The web tool's base prior: rank sum of two Jev scores and wordfreq, packed | Derived from the three files above: CC BY-SA 4.0 |
| `nyt_history.json` | Pinned, unmodified history snapshot: 1,925 days, 2021-06-19 through 2026-09-25 | Collected from the NYT endpoint with `experiments/fetch_history.py` and kept unmodified for exact reproduction. Third-party source data; no new license is asserted here. |
| `history_provenance.json` | Source, file hash and date range of the history snapshot | Reproducibility metadata generated for the September 27 follow-up archive |
